## Назначение

Управление редактором через строку текстовых команд.
Интерфейс и интеграция с VS Code реализованы на JavaScript.
Подсчёт статистики файлов реализован отдельной программой на C++.

## Возможности

- Строка команд с подсказками.
- Иерархические команды и аргументы.
- Имена файлов в двойных кавычках.
- Создание, открытие и сохранение файлов.
- Открытие терминала.
- Переход к строке и выделение диапазона строк.
- Режимы ввода и навигации.
- История до 30 различных команд.
- Статистика файла через C++.

## Команды

| Команда | Действие |
| --- | --- |
| file new notes.txt | Создать файл через диалог |
| file new "my notes.txt" | Создать файл с пробелами в имени |
| file open | Выбрать и открыть файл |
| file save | Сохранить текущий файл |
| terminal | Показать терминал |
| go 15 | Перейти к строке 15 |
| select 5 10 | Выделить строки с 5 по 10 включительно |
| mode insert | Включить обычный ввод |
| mode navigate | Включить навигацию |
| stats | Подсчитать статистику текущего файла |
| history | Повторить команду из истории |

Нумерация строк для пользователя начинается с единицы.

Подсказка подставляет команду в поле ввода.
Пункт «Выполнить» запускает введённую строку.
Esc закрывает строку без выполнения.

История хранится отдельно для текущего проекта.
Записи появляются после обработки команд без ошибки,
включая отменённые файловые диалоги.

## Клавиши

Открытие строки:
- macOS: Cmd+K, затем Cmd+P.
- Windows/Linux: Ctrl+K, затем Ctrl+P.

В редакторе Esc включает навигацию, если нет активных
подсказок, поиска, выделения или режима заполнения сниппета.

В режиме навигации:
- h: влево;
- j: вниз;
- k: вверх;
- l: вправо;
- i: вернуться к вводу.

Режим отображается в строке состояния.

Это упрощённая навигация, а не полная эмуляция Vim.
Другие клавиши сохраняют стандартное поведение редактора.

## Запуск на macOS/Linux

Нужны VS Code, Node.js и компилятор C++ с поддержкой C++17.

1. Открыть папку проекта в VS Code.
2. Выполнить npm run build:native.
3. Выбрать Run → Start Debugging.
4. В тестовом окне вызвать KeyPilot: Open.

Установка npm-зависимостей не требуется.

Для Windows нужно отдельно собрать native/stats.cpp
в native/keypilot-stats.exe средствами установленного компилятора.

## Ограничения статистики

Файл читается с диска.
При несохранённых изменениях предлагается сохранение.

Подсчитываются:
- строки, включая последний непустой участок без перевода строки;
- слова, разделённые ASCII-пробельными символами;
- латинские буквы и цифры;
- байты.

Полная обработка Unicode не реализована.
Пустой файл содержит ноль строк по правилам этого счётчика.

## Автоматическая проверка

После сборки C++ выполнить `npm test`.
Тесты JavaScript используют замену VS Code API и проверяют разбор команд,
историю, переходы, выделение, файловые действия и строку команд.
Тест C++ запускает реальную программу на временных файлах.
Клавиши и интерфейс нужно дополнительно проверить в тестовом окне VS Code.
